# 마이링크 (MyLink) 사용자 시나리오

본 문서는 마이링크 서비스의 주요 사용자별 이용 시나리오를 정의합니다. 모든 시나리오는 "사용자는 __하기 위해 __한다" 형식을 따릅니다.

## 1. 방문자 (Visitor)

### 1.1 페이지 방문 및 열람
*   사용자는 소유자의 통합된 소셜 정보와 웹사이트 목록을 확인하기 위해 제공된 MyLink 고유 URL(`mylink.com/{displayName}`)로 접속한다.
*   사용자는 소유자의 프로필 정보(이미지, 이름, 소개글)와 등록된 전체 링크 목록을 훑어보기 위해 페이지를 상하로 스크롤한다.

### 1.2 링크 이동
*   사용자는 소유자가 운영하는 외부 서비스(블로그, 유튜브 등)로 이동하기 위해 목록에 배치된 특정 링크 카드를 클릭한다.
*   사용자는 소유자의 소셜 계정으로 직접 연결하여 소통하기 위해 SNS 링크 버튼을 클릭한다.

## 2. 소유자 (Owner)

### 2.1 회원가입 및 로그인
*   사용자는 나만의 링크 페이지를 생성하고 관리하기 위해 구글 소셜 로그인을 통해 서비스에 가입하고 인증한다.
*   사용자는 기존에 등록한 링크 정보를 수정하거나 추가하기 위해 다시 구글 계정으로 로그인한다.

### 2.2 프로필 관리
*   사용자는 방문자에게 노출되는 자신의 이름(`username`)을 변경하기 위해 화면 상단의 텍스트를 클릭하여 즉시 수정한다.
*   사용자는 자신을 표현하는 짧은 소개 문구(`bio`)를 업데이트하기 위해 소개글 영역을 선택하여 내용을 입력한다.

### 2.3 링크 관리
*   사용자는 새로운 소셜 채널이나 웹사이트를 방문자에게 공유하기 위해 '링크 추가' 기능을 통해 제목과 URL을 입력한다.
*   사용자는 잘못 입력되었거나 더 이상 유효하지 않은 링크를 목록에서 제거하기 위해 해당 항목의 삭제 버튼을 클릭한다.
*   사용자는 각 링크의 대표 아이콘이 잘 표시되는지 확인하기 위해 자동으로 추출된 파비콘 이미지를 체크한다.

### 2.4 계정 관리
*   사용자는 현재 관리 세션을 종료하고 안전하게 나가기 위해 로그아웃 버튼을 클릭한다.
*   사용자는 본인의 고유 URL 경로가 될 `displayName`이 구글 이메일 ID로 정확히 설정되어 있는지 확인하기 위해 계정 설정 페이지를 확인한다.
