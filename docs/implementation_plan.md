# 링크 관리 기능 구현 계획

## 1. 개요
PRD 요구사항에 따라 링크 추가 기능을 다이얼로그 형태로 구현하고, 링크 삭제 기능을 추가하여 로컬 상태 기반의 링크 관리 시스템을 완성합니다.

## 2. 작업 목표
- [x] `AddLinkDialog` 컴포넌트 구현 및 디자인 고도화
- [x] 메인 페이지(`app/page.tsx`) 내 링크 목록 상태 관리 로직 구현
- [x] 링크 삭제 기능 구현 및 UI 적용
- [x] 전체 UI 디자인 프리미엄화 (애니메이션, 그림자, 유리 효과 등)
- [x] 빌드 및 커밋 검증

- **디자인**: 네오브루탈리즘 + 모던 클린 스타일, Phosphor Icons 사용
