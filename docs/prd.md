# [PRD] 마이링크 (MyLink) - 심플 링크 통합 서비스

## 1. 프로젝트 개요
- **프로젝트명**: 마이링크 (MyLink)
- **목적**: 사용자가 자신의 여러 소셜 링크와 웹사이트 주소를 하나의 간결한 페이지로 모아 관리하고 공유할 수 있는 서비스.
- **대상 사용자**: 개인 SNS 계정 운영자 및 자신의 링크를 정리하고 싶은 일반 사용자.

## 2. 핵심 기능 목록

### 2.1 필수 기능
- **인증 (Firebase Auth)**: 구글 소셜 로그인 단일 방식.
- **프로필 설정**: 
    - `displayName` (화면에 표시될 이름) 필드 필수.
    - 한 줄 소개 및 프로필 이미지 설정.
- **링크 관리**: 
    - 제목 및 URL 입력 기능을 통한 링크 추가 및 삭제.
    - **파비콘 자동 추출**: 입력된 URL의 파비콘을 자동으로 가져와 아이콘으로 설정.
- **디자인 시스템**: **shadcn/ui**를 활용한 모던하고 깔끔한 UI.
- **공개 프로필 페이지**: 반응형 웹으로 구현하여 모든 기기에서 접근 가능.

### 2.2 향후 추가 기능
- **링크 클릭 통계**: 각 링크별 클릭 조회수 트래킹 기능.

## 3. 기술적 요구사항 및 데이터 모델링

### 3.1 데이터베이스 (Firebase Firestore)
- **사용자 정보**: `users` 컬렉션에 저장.
    - 필수 필드: `uid`, `email`, `displayName`, `photoURL`, `bio` 등.
- **링크 데이터**: **서브 컬렉션(Sub-collection)** 구조를 사용.
    - 경로: `users/{uid}/links/{linkId}`
    - 필드: `title`, `url`, `faviconUrl`, `createdAt` 등.

### 3.2 UI/UX 가이드라인
- **shadcn/ui**를 사용하여 일관성 있는 컴포넌트 활용.
- 링크 리스트는 정적인 목록 형태로 제공 (순서 변경 및 활성화 토글 없음).
- 파비콘이 없는 경우 기본 링크 아이콘으로 대체 처리.

## 4. 제약 사항 및 제외 범위
- **순서 변경 불가**: 드래그 앤 드롭 및 링크 순서 조정 기능은 포함하지 않음.
- **활성화 제어 불가**: 링크의 노출 여부를 토글하는 기능은 포함하지 않으며, 삭제를 통해서만 관리함.
- **개발자 특화 기능 제외**: 기술 스택 배지, GitHub 연동 등의 기능은 포함하지 않음.
