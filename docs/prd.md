# [PRD] 마이링크 (MyLink) - 심플 링크 통합 서비스

**Version: v1.1**  
**Last Updated: 2026-05-10**

## 1. 프로젝트 개요
- **프로젝트명**: 마이링크 (MyLink)
- **목적**: 사용자가 자신의 여러 소셜 링크와 웹사이트 주소를 하나의 간결한 페이지로 모아 관리하고 공유할 수 있는 서비스.
- **대상 사용자**: 개인 SNS 계정 운영자 및 자신의 링크를 정리하고 싶은 일반 사용자.

## 2. 핵심 기능 목록

### 2.1 필수 기능
- **인증 (Firebase Auth)**: 구글 소셜 로그인 단일 방식.
- **프로필 관리**: 
    - **닉네임(Nickname)**: 화면에 표시되는 이름이며, 동시에 고유한 URL 경로로 사용됨.
    - **편집 가능**: 프로필 사진(photoURL) 및 닉네임은 언제든 수정 가능해야 함.
- **인라인 편집 (Inline Editing)**: 
    - 별도의 편집 페이지 이동 없이, 대시보드 내에서 즉시 텍스트를 클릭하여 수정하는 인라인 방식 적용.
- **링크 관리**: 
    - 제목 및 URL 입력 기능을 통한 링크 추가 및 삭제.
    - **Google Favicon API 활용**: 입력된 URL의 파비콘을 `https://www.google.com/s2/favicons?domain={domain}` API를 통해 가져와 아이콘으로 설정.
- **디자인 시스템**: **shadcn/ui**를 활용한 모던하고 깔끔한 UI 단일 테마 (테마 선택 기능 없음).
- **공개 프로필 페이지**: `mylink.com/{nickname}` 형식의 주소 제공.

### 2.2 향후 추가 기능
- **링크 클릭 통계**: 각 링크별 클릭 조회수 트래킹 기능.

## 3. 기술적 요구사항 및 데이터 모델링

### 3.1 데이터베이스 (Firebase Firestore)
- **사용자 정보**: `users` 컬렉션에 저장.
    - 필수 필드: `uid`, `email`, `nickname` (URL 식별자), `displayName`, `photoURL`, `bio` 등.
- **링크 데이터**: **서브 컬렉션(Sub-collection)** 구조를 사용.
    - 경로: `users/{uid}/links/{linkId}`
    - 필드: `title`, `url`, `faviconUrl`, `createdAt` 등.

### 3.2 UI/UX 가이드라인
- **shadcn/ui** 컴포넌트를 기반으로 한 인라인 편집 인터페이스 구현.
- 링크 리스트는 정적인 목록 형태로 제공 (순서 변경 및 활성화 토글 없음).
- 파비콘 호출 실패 시 기본 지구본 아이콘 등으로 대체 처리.

## 4. 제약 사항 및 제외 범위
- **순서 변경 불가**: 드래그 앤 드롭 및 링크 순서 조정 기능은 포함하지 않음.
- **활성화 제어 불가**: 링크의 노출 여부를 토글하는 기능은 포함하지 않으며, 삭제를 통해서만 관리함.
- **테마 기능 없음**: 사용자가 배경색이나 템플릿을 변경하는 테마 기능은 제공하지 않음.
- **핸들(@) 미사용**: URL 주소에 `@` 기호를 사용하지 않음.
