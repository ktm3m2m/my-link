# [PRD] 마이링크 (MyLink) - 개발자/크리에이터를 위한 링크트리 클론

## 1. 프로젝트 개요
- **프로젝트명**: 마이링크 (MyLink)
- **목적**: 개발자와 크리에이터가 자신의 기술 스택, 프로젝트, SNS 링크를 세련되게 통합 관리하고 공유할 수 있는 서비스.
- **대상 사용자**: 개발자, 기술 블로거, 오픈소스 컨트리뷰터, 디지털 크리에이터.

## 2. 핵심 기능 목록

### 2.1 필수 기능 (Must-Have)
- **인증 (Firebase)**: 파이어베이스를 이용한 **구글 소셜 로그인** 단일 인증 체계.
- **개발자 프로필 설정**: 프로필 이미지, 닉네임, 한 줄 소개, 그리고 **주요 기술 스택(Tech Stack) 배지** 설정.
- **링크 관리**: 제목, URL, 아이콘 설정 및 활성화/비활성화 스위치.
- **커스텀 URL**: `mylink.com/@username` 형식의 고유 주소.
- **shadcn/ui 기반 디자인**: 모던하고 깔끔한 UI/UX 제공 및 다크 모드 기본 지원.
- **반응형 웹**: 모든 기기에서 최적화된 보기 제공.

### 2.2 선택 및 확장 기능 (Nice-to-Have)
- **방문자 통계 (추후 구현 예정)**: 페이지 뷰 및 링크 클릭 수 분석.
- **GitHub 연동**: GitHub 잔디(Commit Graph) 또는 주요 리포지토리 카드 노출.
- **링크 강조 효과**: 강조하고 싶은 링크에 부드러운 애니메이션 적용.
- **코드 스니펫/터미널 블록**: 간단한 명령어 등을 공유할 수 있는 전용 블록.
- **커스텀 테마**: shadcn/ui 테마 컬러 커스터마이징.

## 3. 기능 상세 설명

### 3.1 인증 및 보안
- **Google Login Only**: 별도의 가입 절차 없이 Firebase Authentication을 통한 구글 로그인으로 즉시 이용 가능.
- **사용자 온보딩**: 첫 로그인 시 고유 사용자 ID(`@username`) 설정 필수 단계 진행.

### 3.2 관리 대시보드
- **shadcn/ui 컴포넌트 활용**: 일관성 있고 세련된 UI 구성.
- **실시간 미리보기**: 링크 수정 및 프로필 변경 사항을 즉시 모바일 뷰로 확인.
- **기술 스택 라이브러리**: 개발자들이 선호하는 기술 스택 아이콘 리스트 제공.

### 3.3 링크 편집기
- **아이콘 자동 매칭**: 입력된 URL에 따라 관련 아이콘(GitHub, LinkedIn, YouTube 등) 자동 추천.
- **상태 제어**: 개별 링크의 노출 여부를 실시간으로 토글링.

### 3.4 프로필 페이지 (공개 모드)
- 개발자/크리에이터 감성에 맞는 미니멀하고 프로페셔널한 디자인.
- 오픈 그래프(OG) 메타 태그 최적화를 통한 소셜 공유 시 가시성 확보.

## 4. 디자인 가이드라인
- **디자인 시스템**: **shadcn/ui**를 전적으로 활용하여 일관된 디자인 언어 유지.
- **감성**: '코드', '깔끔함', '신뢰성'을 키워드로 한 모던한 디자인.
- **접근성**: 다크 모드를 우선적으로 고려한 컬러 팔레트 구성.

## 5. 기술 스택 (확정 사항)
- **Frontend**: Next.js / React (추정)
- **UI Library**: shadcn/ui
- **Backend/Auth**: Firebase (Auth, Firestore 등)
